# Afinador

Afinador cromático sencillo: nota, desviación en cents, trompeta en Si♭ y violín.

Sin anuncios. Todo se queda en tu móvil; solo se conecta a GitHub para buscar actualizaciones (se puede desactivar en Ajustes).

## Instalar

1. Descarga el `.apk` de la última [release](https://github.com/rosauro/afinador-android/releases/latest) (y comprueba el `.sha256`).
2. Permite «Instalar apps desconocidas» al navegador o gestor de ficheros.
3. Android puede mostrar un aviso de **Play Protect** porque la app no viene de Google Play: pulsa «Más detalles → Instalar de todas formas».

## Desarrollo

```bash
source /datos/android-sdk/env.sh
./gradlew --no-daemon testDebugUnitTest assembleDebug
```

# Afinador (English)

Simple chromatic tuner: note, cents deviation, B♭ trumpet and violin. No ads. Everything stays on your phone; it only connects to GitHub to look for updates.

Install: download the `.apk` from the [latest release](https://github.com/rosauro/afinador-android/releases/latest), allow “Install unknown apps”, and if **Play Protect** warns you, choose “More details → Install anyway”.
